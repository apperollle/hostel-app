  HOSTEL APP — как открыть сайт (1 клик)
═══════════════════════════════════════════════════

1. Установите Python (если ещё нет):
   https://www.python.org/downloads/
   При установке обязательно включите галочку:
   ☑ Add python.exe to PATH

2. Дважды щёлкните по файлу:

      start.bat

   (он лежит в этой же папке hostel-app)

3. Откроется чёрное окно и браузер со ссылкой:

      http://127.0.0.1:5000

   Пока окно открыто — сайт работает.
   Закрыли окно — сайт выключился (это нормально).

───────────────────────────────────────────────────
  Если start.bat пишет ошибку про pip / SOCKS
───────────────────────────────────────────────────

Откройте PowerShell в этой папке и выполните:

   python -m venv venv
   .\venv\Scripts\pip install PySocks
   .\venv\Scripts\pip install Flask Werkzeug

Потом снова запустите start.bat
