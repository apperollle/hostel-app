# Hostel App

Веб-сервис поиска и бронирования хостелов.

**Стек:** Python, Flask, SQLite, HTML, CSS, JavaScript.

## Возможности

- Поиск хостелов по городу и датам
- Карточки хостелов с ценами и рейтингом
- Страница хостела с номерами и проверкой свободных мест
- Регистрация и **вход пользователя** (поиск, брони, отзывы)
- **Вход администратора** — отдельная страница `/admin/login`
- Админ-панель: добавление, редактирование и удаление хостелов и номеров
- Бронирование и отмена (только для пользователей)
- Отзывы (один отзыв на хостел от пользователя)

## Запуск в один клик (Windows)

1. Установите [Python](https://www.python.org/downloads/) с галочкой **Add to PATH**.
2. Дважды щёлкните **`start.bat`** в папке проекта.
3. Откроется браузер: **http://127.0.0.1:5000**

Пока открыто окно `start.bat` — сайт работает. Закрыли окно — сервер остановился.

Подробнее: файл `КАК_ЗАПУСТИТЬ.txt`

## Запуск вручную

```powershell
cd C:\Users\danya\hostel-app
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Откройте в браузере: http://127.0.0.1:5000

## Вход

| Роль | Страница | Email | Пароль |
|------|----------|-------|--------|
| Пользователь | `/login` | demo@hostel.app | demo123 |
| Администратор | `/admin/login` | admin@hostel.app | admin123 |

Учётные записи разделены: админ не может войти через `/login`, пользователь — через `/admin/login`.

База SQLite создаётся автоматически в файле `hostel_app.db` с тестовыми хостелами в 4 городах.
